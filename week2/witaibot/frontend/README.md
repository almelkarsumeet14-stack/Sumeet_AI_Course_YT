# WIT AI Bot Frontend

## Setup
1. Open this `frontend` folder in VS Code.
2. Run `npm install`.
3. Run `npm run dev`.
4. Keep the FastAPI backend running at `http://127.0.0.1:8000`.

Optional `.env`:
VITE_API_URL=http://127.0.0.1:8000

Features:
- Professional WIT campus themed UI
- Real backend `/chat` integration
- Working New Chat
- Working local browser chat history
- History restore and clear
- Sidebar navigation shortcuts
- Light/Dark toggle
- Responsive design
- Suggested questions
- Official WIT website links
